# Aplicativo Calculadora

Aplicación de consola desarrollada en Java durante la carrera de desarrollo de
aplicaciones móviles. Permite realizar las operaciones básicas: suma, resta,
multiplicacion y division mediante un menu interactivo.

## Funcionalidades

- Suma
- Resta
- Multiplicacion
- Division (con validacion de division por cero)
- Ciclo de ejecucion hasta que el usuario decida salir

## Como ejecutar

1. Compilar: javac Calculadora.java
2. Ejecutar: java Calculadora
